# OpenTS Subtitles

مجموعه‌ای مشارکتی برای نگهداری و بهبود زیرنویس فارسی و انگلیسی ویدیوهای مرتبط با مهندسی نرم‌افزار. هدف این پروژه آن است که هرکس بتواند اشتباهات پیاده‌سازی، ترجمه یا زمان‌بندی را گزارش کند و برای بهبودشان Pull Request بفرستد.

## ویدیوها

| عنوان | سخنران | رویداد | فایل‌ها |
| --- | --- | --- | --- |
| What is DDD? | Eric Evans | DDD Europe 2019 | [مشاهده](videos/ddd-europe/2019-what-is-ddd-eric-evans/) |

در پوشهٔ هر ویدیو، `subtitles/en.srt` متن انگلیسی و `subtitles/fa.srt` ترجمهٔ فارسی است. وضعیت بررسی و منبع فایل‌ها در README همان ویدیو آمده است. این نسخه‌ها نیاز به بازبینی دارند؛ فایل انگلیسی را لزوماً زیرنویس رسمی در نظر نگیرید.

## مشارکت

اشتباهی دیدید؟ برای تغییر کوچک می‌توانید مستقیماً فایل را در گیت‌هاب ویرایش کنید و Pull Request بفرستید؛ یا ابتدا Issue باز کنید. پیش از شروع، [راهنمای مشارکت](CONTRIBUTING.md) و [واژه‌نامه](GLOSSARY.md) را ببینید.

## بررسی فایل‌ها

برای اجرای بررسی ساختار SRT با Python 3:

```bash
python scripts/validate_subtitles.py
```

هشدارهای هم‌پوشانی مانع اجرا نمی‌شوند و برای بازبینی انسانی هستند.

## منابع و حقوق

منبع هر ویدیو در پوشهٔ خودش ذکر شده است. پیش از انتشار عمومی، وضعیت اجازهٔ استفاده و انتشار متن و ترجمه‌ها را برای هر اثر بررسی و مستند کنید. برای جزئیات به [COPYRIGHT.md](COPYRIGHT.md) مراجعه کنید.
